## Giới thiệu (About)

Đây là dự án cá nhân được viết tay để dành tặng một người đặc biệt — kết hợp thiết kế giao diện, hiệu ứng và nội dung được cá nhân hóa. Dự án tập trung vào trải nghiệm và cảm xúc người xem hơn là tính năng phức tạp, phù hợp để triển khai như một trang web tĩnh (static site), có thể host miễn phí trên GitHub Pages.

## Cách xem / chạy thử

Vì đây là website tĩnh, không cần cài đặt hay build gì phức tạp:

```bash
git clone https://github.com/nhunguy-swe/a-little-gift.git
cd a-little-gift
```

Sau đó mở trực tiếp file `index.html` bằng trình duyệt, hoặc dùng extension **Live Server** trong VS Code để có trải nghiệm tốt hơn (tự động reload khi chỉnh sửa).

### Deploy miễn phí với GitHub Pages

1. Vào **Settings → Pages** của repo.
2. Chọn nhánh `main` và thư mục gốc (`/root`) làm nguồn deploy.
3. Sau vài phút, trang web sẽ có sẵn tại: `https://nhunguy-swe.github.io/projectForPartner/`

## Về việc sử dụng làm template

Repo này hiện được bật chế độ **Template repository** trên GitHub, nghĩa là người khác có thể dùng nó làm khuôn mẫu để tạo dự án tương tự (nút **"Use this template"**). Nếu bạn không muốn chia sẻ công khai theo hướng này, có thể tắt tùy chọn đó trong **Settings → General → Template repository**.
